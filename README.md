# 贴吧相册下载器

一个 Windows 图形化小工具：把贴吧「相册」链接粘贴进去，登录百度账号，**一键把整个贴吧的相册图片、按原顺序保存到本地**，并生成**原版贴吧视觉的离线 HTML**（含图片评论），方便在贴吧相册功能下线前备份。

> 仅供个人备份收藏，图片版权归原作者。

## 重要事实（实测结论）

1. **贴吧全站不保存「上传者的原始文件名」**。接口里只有 `pic_id`（40 位哈希）和 `descr`（图片描述）。
   `descr` 是贴吧里最接近「原名」的字段（红警3吧里是「0将军刽子手0」「动画版 by 真空菊爆器」这类真实文字）。
   因此图片按你选定的 **`序号_描述.ext`** 命名（序号保证原顺序，描述保留可读原意；无描述时回落到 `pic_id`）。
2. **相册列表页必须登录 + 真实浏览器**。贴吧对 curl / 无头 CLI 一律返回「百度安全验证」拦截页（实测：Edge 无头 `--dump-dom` 也被拦）。
   图片清单接口和评论接口本身**不需要登录**，但相册列表是在登录态下才能拿到内容的。
3. **接口全站 GBK 编码**。所有 JSON 响应按 GBK 解析（不是 UTF-8），否则中文乱码。
4. **图片顺序**由接口返回的 `index` 字段保证（实测某相册 708/708 连续无缺）。
5. **离线 HTML 采用贴吧原版视觉还原**：三层页面（吧级墙 / 单本相册墙 / 单图帖页），引用备份时从相册列表页抽取的**真实贴吧 CSS**（`static/tieba_core.css`）；抽不到时自动用内置 fallback 样式兜底，不至于裸奔。

## 离线 HTML：原版贴吧视觉还原

布局与现网贴吧尽量一致，分三层：

```
输出目录/
  红警3/                              # 吧名（kw）
    相册列表.html                     # L1 吧级相册墙（索引）：所有相册封面网格
    相册列表_原始快照.html            # 相册列表页原始 DOM 存档（排错用）
    static/tieba_core.css             # 运行时从列表页抽取的贴吧核心 CSS（还原用）
    manifest.json                     # 顺序/描述/源URL/本地路径/评论 清单
    本吧吧徽.html                     # L2 单本相册墙：缩略图网格，点图进帖页
    本吧吧徽/图片/
        001_动画版 by 真空菊爆器.jpg  # 序号_描述.ext，按原顺序
    本吧吧徽/帖子/
        001_动画版 by 真空菊爆器.html # L3 单图帖页：大图 + 楼主描述 + 评论楼
    吧友真人秀.html
    吧友真人秀/图片/…
    吧友真人秀/帖子/…
```

- **L1 索引墙** `相册列表.html`：所有相册卡片，点进各本相册墙。
- **L2 相册墙** `<相册名>.html`：该相册缩略图墙，点图进对应帖页。
- **L3 帖页** `<相册名>/帖子/<序号_描述>.html`：大图 + 楼主描述 + 评论楼（评论用接口全量注入，比原页更全）。
- 三层页面都引用 `static/tieba_core.css`（备份时从相册列表页抽取的真实贴吧 CSS）；抽不到时自动用内置 fallback 样式兜底。
- `<img src>` 一律指向本地图片，双击即可离线浏览；图片按原顺序、评论嵌在对应帖页下方。

界面提供「**原版贴吧视觉还原（取消=旧网格）**」勾选（默认勾选）。取消则退回旧版单页网格模式。

## 使用（打包后的 EXE）

1. 解压发布包，双击 `贴吧相册下载器.exe`（发布版位于 `dist\贴吧相册下载器\贴吧相册下载器.exe`）。
2. 在「相册链接」填入贴吧相册链接（如 `https://tieba.baidu.com/f?kw=红警3&ie=utf-8&tab=album`），或直接填「贴吧名称」。
3. 首次使用点「**登录百度账号**」→ 弹出浏览器窗口，登录百度账号（只需一次，会话自动保存到本机 profile，以后免登录；登录窗口同时帮你在相册列表页过掉安全验证）。
4. 点「**开始保存**」→ 界面显示实时进度（相册数 / 图片下载 / 评论抓取），完成后一键「打开输出目录」。

> 输出目录每次都会弹框让你选择，默认建议 `D:\贴吧相册备份`（不写 C 盘）。

## 环境要求

- Windows 10 / 11。
- 已安装 **Microsoft Edge**（系统自带，工具复用其内核；Playwright 版也可回退到系统 Chrome 或自带 Chromium）。
- 首次运行需联网并登录一次百度账号。

## 两种发布包

| 版本 | 体积 | 依赖 | 适用 |
|------|------|------|------|
| **Playwright 版**（默认） | ~146MB | 自带浏览器驱动，最稳 | 保命备份、给别人分享，开箱即用 |
| **CDP 瘦身版** | ~43MB | 要求目标机已装 Edge/Chrome | 自己用、网速慢、想轻量 |

两个版本代码完全一致，只是打包时排不排除 `playwright`。程序会自动选择可用的浏览器后端（有 playwright 用 playwright，没有则直连系统 Edge 走 CDP）。

## 常见问题与排错

- **卡在「安全验证」**：在弹出的浏览器窗口里手动完成滑块验证即可；若提示未登录，先点「登录百度账号」。
- **「未解析到相册 / 相册数=0」**：几乎都是「未登录」。请先点「登录百度账号」登录成功后再点「开始保存」。已登录仍 0 本，可看 `相册列表_原始快照.html` 核对页面结构。
- **个别图片下载失败**：日志会标记失败项；已下载成功的图片再次运行会跳过（断点续传）。
- **评论抓不全/想加速**：界面可取消「抓取评论」勾选，或填「每图最多 N 条」。
- **打包后窗口程序看不到报错**：异常会写到 exe 旁边的 `启动错误.log`；命令行 `--selftest` 的结果写到 `selftest_result.txt`。

## 开发者：本地运行与打包

```bat
:: 1) 依赖
pip install playwright lxml pyinstaller
playwright install msedge      :: 或复用系统 Edge，不必装

:: 2) 命令行试跑（调试用）
python crawler.py --kw 红警3 --out-dir 输出         # 抓取（图片接口免登录）
python crawler.py --kw 红警3 --out-dir 输出 --no-comments   # 不抓评论，更快
python crawler.py --login                         # 只打开登录窗口
python crawler.py --selftest                      # 本地自检（不联网：GBK/分页/命名/评论/续传/HTML）
python app.py                                     # 直接启动 GUI

:: 3) 打包（也可用 build.bat 一键完成）
python -m PyInstaller tieba_album_getter.spec            # Playwright 版 → dist\贴吧相册下载器\
python -m PyInstaller tieba_album_getter_slim.spec       # CDP 瘦身版  → dist\贴吧相册备份工具(瘦身版)\
```

> 沙箱/受限环境下 PyInstaller 的 `--clean` 与 `rm -rf` 会被拦截。重打包前先把旧 `dist\<名字>\` 改名移走（不要删），再不带 `--clean` 直接打包即可。`build.bat` 已按此安全模式编写。

## 已知限制

- 相册列表页依赖真实浏览器渲染 + 登录会话，沙箱 / 受限网络下贴吧会返回 403 属正常反爬，请在本机正常网络下运行。
- 贴吧服务端 `total_num` 有时会多计 1（含已删除图片），属数据源问题，不是抓取遗漏（会显示「接口报告 N 张，实际保存 N-1 张」）。
